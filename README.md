# Maerno-Mathematics
Creating a mathematical language.

## Symbols
### Work:
? (Question mark => Lectro) = Theory to be expanded  
» (Right angled quote => This objectively means there is in (subsists in)
Ô (O-circumflex upper => Objeto) = Object in our theoretical world  
€ (NAME => Es) = Is
§ (Section => Supongo) = Suppose, give any logical example  
¿ (Inverted question mark => Metro) = Does this mean that
‽ (Interrobang => Casi) = Last step left  
¡ (Inverted exclamation => Fin) = Completed part (yes it does)  
‼ (Dagger => Fin Completo) = Complete whole (it works out)  
¢ (Cent => Pues) = Then
$ (Dollar => Impongo) = I impose this claim to start test phase and test my work
† (Double exclamation => Prueba) = Test question of work (test phase)  
‡ (Double dagger => Otra prueba) = I will show another test

? By definition of a square, all sides must be equal.
